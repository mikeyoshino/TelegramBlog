# QR-first sign-in update

Approved by user: QR login as primary flow, phone login as fallback, remove API credential form from normal user flow.

Design: first launch shows Connect Telegram and scan instructions. Pressing Connect obtains a real, automatically renewed Telegram QR token. Scan in Telegram mobile Settings > Devices > Link Desktop Device. Ask for 2FA only if Telegram requires it. Switching modes/restarting/closing cancels pending QR and password requests; late callbacks cannot sign in or change the screen. Existing sessions still resume automatically.

Developer credentials remain necessary. Load them from local telegram.json, environment, or previously protected configuration; missing configuration produces a specific build-not-configured explanation. Never generate fake login QR or use someone else's credentials. No API fields/browser developer links in the normal screen. Explicit white background corrects the unwanted inherited window tint.
