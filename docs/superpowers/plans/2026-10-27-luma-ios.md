# Luma iOS Implementation Plan

> **For agentic workers:** Execute inline using superpowers:executing-plans; follow the approved iOS handoff.

**Goal:** Deliver an independently buildable iPhone app faithfully reproducing Luma with Telegram integration.
**Architecture:** Separate MAUI iOS host with bundled HTML/CSS and HybridWebView messages. Share Telegram and Core; inject Keychain session persistence without changing Windows defaults.
**Tech Stack:** .NET 10 MAUI, WKWebView, JavaScript, iOS Keychain, native share/video.
**Spec:** docs/IOS-HANDOFF.md and docs/design/luma-mobile.html (existing agreed design).

## Global Constraints
- Preserve desktop UI and behavior; no credentials committed.
- Real safe areas/status bar; no decorative device frame.
- Reference white/blue palette, typography, square grid, floating navigation, sheets, viewer.
- Preview fixtures explicitly labeled and isolated from real accounts.
- Counts describe loaded data only; no invented file sizes/durations.

## Review Focus
- Account switching must clear old content and scope favorites.
- Late history/media responses must not replace current selection.
- Keyboard and narrow/landscape viewports must keep actions reachable.
- Offline errors must retain previously visible content and offer retry/cancel.
- Closing/backgrounding video must release playback and temporary files.
