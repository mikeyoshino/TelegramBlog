# คอลเลกชันสำหรับรายการที่เก็บไว้ใน Luma

สถานะ: ผู้ใช้ยืนยันแบบแล้วในบทสนทนา และพัฒนาเสร็จ

## เป้าหมายและขอบเขต

ช่วยให้กลับมาหารูป คลิป และข้อความ/ลิงก์ที่บันทึกไว้ได้ง่าย โดยต่อยอดหน้า “เก็บไว้” และ SQLite ต่อบัญชีที่มีอยู่ ข้อมูลนี้เป็นรายการที่เก็บใน Luma บนเครื่อง ไม่ได้สร้างโฟลเดอร์หรือย้ายข้อความใน Telegram Saved Messages

ผู้ใช้เลือกแล้วว่า **หนึ่งข้อความอยู่ได้หนึ่งหมวด** รวมไฟล์แนบทั้งหมดของข้อความนั้นเป็นรายการเดียว ย้ายหมวดได้โดยไม่เสียโน้ตหรือสถานะ

## แนวทางที่พิจารณา

- หนึ่งข้อความต่อหนึ่งหมวด: เข้าใจง่าย ย้ายหมวดได้ชัดเจน — ผู้ใช้เลือกแนวทางนี้
- หนึ่งข้อความหลายหมวด: จัดซ้ำได้ยืดหยุ่น แต่เพิ่มความซับซ้อนในการเลือกและจัดการ — ไม่ใช้

## หน้าจอและการใช้งานที่เสนอ

1. หน้า “เก็บไว้” มีค้นหาชื่อ/ข้อความ/โน้ต ตัวเลือกหมวด “ทั้งหมด”, “ยังไม่จัดหมวด” และหมวดที่สร้าง พร้อมตัวกรอง “ทั้งหมด / ยังไม่ได้ดู / ดูแล้ว”
2. การ์ดแสดงภาพปกหรือข้อความ ชื่อหมวด สถานะ และโน้ตสั้น ๆ มีปุ่มเมนูแยกจากการแตะเพื่อเปิดดูสื่อ เพื่อไม่รบกวนการเล่นวิดีโอและดูภาพ
3. เมนูการ์ดมี “เก็บเข้าคอลเลกชัน”, “แก้ไขโน้ต”, “ทำเครื่องหมายว่าดูแล้ว/ยังไม่ได้ดู” และ “ไปข้อความต้นทาง” ในตัวดูสื่อมีทางเข้าจัดการรายการเดียวกัน
4. เลือกหมวดได้หนึ่งรายการ หรือสร้างหมวดใหม่ในหน้าต่างเดียวกัน เลือกหมวดใหม่คือย้าย ไม่คัดลอกข้อความ
5. บันทึกโน้ตเมื่อกด “บันทึก” มีปุ่มยกเลิก การเปิดดูสื่อเฉย ๆ ไม่เปลี่ยนสถานะดูแล้วโดยอัตโนมัติ
6. เปลี่ยนชื่อและลบหมวดได้ ลบหมวดต้องยืนยัน และย้ายรายการไป “ยังไม่จัดหมวด” โดยเก็บภาพ โน้ต และสถานะไว้
7. รายการเดิมเริ่มใน “ยังไม่จัดหมวด” สถานะ “ยังไม่ได้ดู” ซึ่งเป็นสถานะใน Luma แยกจากจำนวนข้อความที่ยังไม่อ่านใน Telegram

## การเก็บข้อมูลและข้อกำหนดทางเทคนิค

- เพิ่มตารางหมวด และข้อมูลประกอบรายการโปรด (หนึ่งแถวต่อ post ID: collection ID แบบ nullable, note, viewed) ใน SQLite เดิม แยกจาก payload และไฟล์สื่อ เพื่อไม่ให้การรีเฟรช Telegram เขียนทับโน้ต
- อัปเกรด schema แบบเพิ่มตารางโดยไม่ลบข้อมูลเดิม ป้องกันหมวดชื่อซ้ำหลังตัดช่องว่าง และชื่อว่าง
- บันทึกการย้าย/แก้ไขผ่าน transaction และ gate ของรายการโปรดเดิม ป้องกันการเขียนข้ามบัญชีเมื่อออกจากระบบ
- จัดหมวด แก้โน้ต และสถานะของรายการที่บันทึกแล้วได้โดยไม่ต้องดาวน์โหลดสื่อใหม่ และใช้งานขณะออฟไลน์ได้
- ใช้การเปิดต้นทางที่มีอยู่ หากไม่มีลิงก์แสดงข้อความแจ้งที่เข้าใจได้
- รองรับข้อความ/ลิงก์ที่มีอยู่ในรายการที่บันทึกไว้ การดึงข้อความแบบไม่มีสื่อเข้าคลังและการนำเข้า Telegram Saved Messages ทั้งห้องเป็นงานแยก ไม่รวมในรอบนี้
- คงวิธีเก็บรูปต้นฉบับและ thumbnail วิดีโอเดิม ไม่เปลี่ยนเป็นดาวน์โหลดวิดีโอทั้งไฟล์

## การตรวจสอบก่อนส่งมอบ

- SQLite: เปิดแอปใหม่ข้อมูลยังอยู่ ย้ายได้หมวดเดียว ลบหมวดแล้วรายการ/โน้ตไม่หาย แยกข้อมูลแต่ละบัญชี และรักษารายการเก่า
- UI: สร้าง/เลือก/ย้ายหมวด แก้/ยกเลิกโน้ต กรองและค้นหา เปลี่ยนสถานะ เปิดต้นทาง และจัดการข้อผิดพลาดโดยไม่แสดงผลสำเร็จก่อนบันทึกจริง
- ตรวจหน้าจอขนาด iPhone และการดูภาพ/เล่นวิดีโอเดิม จากนั้น build และอัปเดตแอปบนเครื่องที่เชื่อมต่อโดยไม่ถอนการติดตั้ง

## ปรับขั้นตอนกดเก็บตามคำขอเพิ่มเติม

การเก็บครั้งแรกในรอบเปิดแอปถามหมวดและสร้างหมวดใหม่ได้ในหน้าต่างเดียวกัน ยกเลิกก่อนยืนยันไม่บันทึกโพสต์ ครั้งถัดไปใช้หมวดที่เพิ่งเลือกสำเร็จโดยอัตโนมัติ จำเฉพาะในหน่วยความจำของบัญชีนี้ และถามใหม่เมื่อเปิดแอปใหม่หรือไม่มีการเก็บสำเร็จ 30 นาที (ค่าเริ่มต้นที่แจ้งผู้ใช้) หมวดถูกลบต้องถามใหม่ การเก็บพร้อมหมวดใช้ SQLite transaction เดียวเพื่อไม่เหลือโพสต์ไร้หมวดเมื่อการกำหนดหมวดล้มเหลว ครอบคลุมการเลือกเก็บหลายโพสต์ด้วย
